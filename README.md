# PubHealthArcDev

Public Health Disease Surveillance Architecture Development Project

The Projects objective was to simulate development of health system and public health operating systems. This project used vmware, school built/maintained network infrastructure, virtual ubuntu linux computers, and open source EMRs.

The biggest struggle I encountered during this project was getting cmd codes to run. That was the biggest frustration. 

The biggest achievement was seeing properly installed and function servers running an open source EMR.
